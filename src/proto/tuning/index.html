Tuning panel

Step 1a4. Sliders bound straight to a config object the sim reads every tick. This is the tool the kart gets tuned with in 1b — and the reason the tuning log writes itself.

Something to tune

A bouncing ball, standing in for the kart. Click the canvas to launch it from that spot. Every slider below changes the sim mid-flight — nothing reloads, nothing restarts.

Why the copy buttons matter

The panel snapshots the values the code shipped with and never touches that baseline. So it can hand you a paste-ready TUNING.md entry listing before → after for exactly the fields you moved, with the “why” left blank for you. That is the log the plan asks for, minus the part where someone has to remember to write it.

Copy config gives you the whole object as TypeScript, ready to paste back into the source once a value is signed off.
